API at a glance

RouteResponse
GET /api/v1/proxiesPaginated proxy records, total count, next offset and snapshot revision.
GET /proxies.txtOne IP:port per line. Accepts the same filters.

GET /healthMinimal listener health response.

Use from a script

curl -H "X-Api-Key: YOUR_KEY" \
  "http://YOUR_SERVER:8088/api/v1/proxies?type=socks5&country=US,DE&https=true&format=json&limit=100&sort=ping"

Optional filters: max_ping (TCP milliseconds), max_age_hours, offset and sort=endpoint|ping. Default: HTTPS-verified results, 1,000 records. Maximum: 10,000 records per response. Use country=ZZ for unknown locations. Compare snapshot revisions when paging across a refresh.

Protected endpoints also accept Authorization: Bearer YOUR_KEY. Keys are never accepted in URLs. Serve remote authenticated traffic through an HTTPS reverse proxy. A healthy listener does not guarantee a fresh proxy list; check publishedUtc and each record's checkedUtc.

راهنمای فارسی

فهرست پروکسی‌های بررسی‌شده را با فیلتر کشور، نوع و HTTPS دریافت کنید. قالب txt برای فهرست ساده و json برای جزئیات کامل است. در حالت محافظت‌شده، کلید را در هدر X-Api-Key بفرستید؛ کلید داخل لینک پذیرفته نمی‌شود. کشور ZZ یعنی موقعیت نامشخص. فهرست قبلی تا پایان دور جدید در دسترس می‌ماند و نتایج قدیمی‌تر از زمان مجاز حذف می‌شوند.
